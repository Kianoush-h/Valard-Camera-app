# Valard Camera

Timestamp camera web app for Valard crews. Take a photo, check the stamp, approve it, and it is uploaded automatically.

Each photo is stamped with:
- Network and local date/time with time zone
- GPS coordinates (degrees / minutes / seconds)
- Compass heading
- Street address
- Satellite mini-map with your position
- Compass rose
- Photographer name

Developed by Kianoush Haratiannejadi.
